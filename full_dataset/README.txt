Datasets for C2 Benchmark
=========================

words/words-470k.txt
  English dictionary words (~467K keys, 4.6 MB).
  Source: https://github.com/dwyl/english-words

url/uk-2014-tpd_sorted.ids
  UK private domain names from a 2014 web crawl (~1.77M keys, 36.7 MB, sorted).
  Source: http://uk-domain-lists.com / web crawl dataset (uk-2014-tpd)

dna/dna100_31mers_sorted.txt
  Non-overlapping 31-mers extracted from the Pizza&Chili DNA 100MB prefix,
  sorted and deduplicated (~3.32M keys, 102 MB).
  Source: https://pizzachili.dcc.uchile.cl/texts/dna/dna.100MB.gz

xml/dblp.xml.200MB_sorted
  Lines from a 200MB prefix of the dblp XML bibliography dump,
  sorted and deduplicated (~2.15M keys, 117 MB).
  Source: https://pizzachili.dcc.uchile.cl/texts/xml/dblp.xml.200MB.gz

log/access_log_common_sorted.txt
  Web server access log entries in Apache Common Log Format (referrer and
  user-agent fields stripped), sorted and deduplicated (~4.45M keys, 586 MB).
  Source: https://www.kaggle.com/datasets/eliasdabbas/web-server-access-logs

wiki/enwiki-ns0-ascii.txt
  English Wikipedia article titles (namespace 0, ASCII-only, sorted),
  from the April 2026 dump (~17.5M keys, 359 MB).
  Source: https://dumps.wikimedia.org/enwiki/20260401/enwiki-20260401-all-titles-in-ns0.gz
